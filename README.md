# Tazkiyah Noor — Demo APK

![Tazkiyah Noor demo](sell-poster.png)

Tazkiyah Noor is a polished Flutter Islamic app experience combining Quran,
prayer times, Qibla, duas, tasbih, reminders and travel mode.

## Download

Open the latest release and download the APK:

[Download the latest demo APK](../../releases/latest)

## Features shown in the demo

- Local Quran text
- Location-based prayer times
- Qibla compass and map
- Duas and tasbih
- Bengali and English interface
- Prayer reminders and alarm settings
- Travel mode and persistent preferences

## Important

This repository contains a demo APK only. It does not contain the full source
code, private API credentials or backend source. Recitation audio may require an
internet connection and device permissions are requested during onboarding.
